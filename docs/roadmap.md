# Roadmap 迭代计划

## 已发布

### v1.0 — 核心功能（Fyne 版）

- [x] 曲库扫描（mp3/flac/wav/ogg，增量更新）
- [x] ID3/FLAC/Vorbis 标签与内嵌封面
- [x] 播放/暂停/上下曲/进度/音量/四种播放模式/自动切歌
- [x] 歌单管理（增删改查、添加/移除歌曲）
- [x] 收藏与播放历史
- [x] LRC 本地歌词同步显示
- [x] 内嵌 Gin API + 局域网远程控制

### v1.0.1 — 音频修复（用户反馈驱动）

- [x] 播放前统一重采样到 44100Hz：48k/96k/192k 音源（含 24bit WAV）变速变调问题修复
- [x] 扫描进度回调走主线程，消除 Fyne 线程违规警告

### v1.0.2 — UI 迁移与体验完善

- [x] UI 从 Fyne 迁移至 **Wails v2 + Vue 3 + Naive UI**（exe 80MB → 30MB）
- [x] 桌面窗口与远程控制**共用同一套前端**（双模式：Go 绑定 / HTTP API）
- [x] 扫描完成自动重载列表 + 完成提示；启动自动扫描
- [x] 服务端静态资源强制 no-store，杜绝旧前端缓存问题
- [x] 列表整表滚动浏览 + 亮色滚动条 + 表格卡片化（视觉反馈明确）
- [x] 应用命名「堆栈音乐播放器」，侧栏版本指纹

## v1.1（近期候选）

- [ ] **托盘常驻**：关闭窗口不退出，托盘菜单控制播放/退出
- [ ] **播放队列界面**：显示当前队列，支持拖动排序、移除
- [ ] **列表多选与批量操作**：批量加入歌单、批量删除、全选
- [ ] **随机播放加权/防重复**：洗牌不重复直到播完一轮
- [ ] **自动恢复上次播放**：记住歌曲与进度，重启后继续
- [ ] **封面大图与专辑视图**：按专辑分组的曲库浏览
- [ ] **在线歌词搜索**：按「标题+艺术家」自动从互联网匹配歌词（注意版权合规，做成可关闭的选项）
- [ ] **超大曲库虚拟滚动**：歌曲超万首时启用 NDataTable virtual-scroll

## v1.2（中远期）

- [ ] **远程音频流**：`/api/stream/:id` 转发音频，手机浏览器直接点播（需转码/限流设计）
- [ ] **移动端优化控制页**：PWA 化、显示播放列表/歌单管理
- [ ] **均衡器（EQ）**：基于 beep 效果器的十段 EQ
- [ ] **全局快捷键**：媒体键（播放/暂停/上下曲）
- [ ] **音频可视化**：频谱动画
- [ ] **单实例锁**：防多开重复占用 8080 与数据库写冲突
- [ ] **Web/移动端远程歌词**：控制页同步显示歌词
- [ ] **曲库标签管理**：批量编辑 ID3 标签
- [ ] **扫描失败报表**：解码失败文件列表展示

## 决策待定项

| 议题 | 说明 |
|---|---|
| 在线歌词/曲库接口 | 涉及版权与接口稳定性，需用户明确授权后实施 |
| 音频转码 | beep 为纯 Go 解码，无编码能力；远程流式转码需引入 ffmpeg 外部进程或原生编码库（CGO） |
| 鉴权方式 | 远程控制页接入最简单可用鉴权（如固定口令 + Cookie），防局域网内误操作 |
